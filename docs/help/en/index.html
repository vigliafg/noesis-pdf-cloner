Noesis PDF Cloner — Help

Welcome to the complete guide. Noesis PDF Cloner opens a PDF and shows the original page on the left and the same page translated with its layout preserved on the right. Here you will find a description of the features, how to use the translation engines, how the OpenRouter key is managed, export, installation and lawful use of the program.

Overview

The translated clone is produced by pdf2zh_next v2 (typesetter BabelDOC): text, images, columns, tables and formulas stay in place, while the text is translated into the chosen language. Translation is on-demand, page by page, with a disk cache kept separately for each engine and language pair.

📖 Side-by-side view

Original page on the left, translated clone on the right, with synchronized zoom.

🧩 Layout preserved

The clone keeps the page's layout, figures, tables and formulas.

🌐 Three engines

Google (free chain with fallback), Bing and LLM via OpenRouter.

▶ On-demand translation

The page starts only from the ▶ Translate button: no automatic translation while browsing.

🗂️ Cache per engine

On the second access the page is instant; when you change engine the app asks for confirmation.

💾 Guided export

5-step wizard: a single merged PDF or individual pages in a ZIP.

🔑 Protected key

The OpenRouter key is stored in a per-user file (0600) with verification.

🌍 Multilingual interface

Italiano, English, Français, Deutsch, Español — switchable on the fly.

At a glance

  • Side by side: original and clone always compared.
  • Control: translation starts only when you want it.
  • No keys to get started: Google and Bing are free.

Getting started

  1. Launch the application (see Installation) and make sure the cloning engine is installed.
  2. Click 📂 Open PDF in the toolbar and choose a file.
  3. In ⚙️ Settings choose the document language (source, including auto) and the translation language (target).
  4. Choose the engine in the bar of the right-hand panel (Google, Bing or LLM).
  5. Press ▶ Translate: the clone appears on the right with its layout intact.
  6. With 💾 Export you save the page or a range (see Export).
Tip On first opening the app can resume from the last page of the document (if the option is enabled) and uses the chosen interface language. Translation does not start by itself: the ▶ Translate button is always required.

Left panel — original

Shows the PDF page as it is, with the optional table of contents (TOC). Zoom is shared with the right panel, so the two sides stay aligned.

Right panel — translated clone

At the top is the engine bar with the radio buttons Google / Bing / LLM and the ▶ Translate button. The bar is collapsible (chevron at the top right): when collapsed the space returns to the page, which reflows, and the state is remembered between sessions.

  • “Missing engine” banner — if the engine is not installed, a banner appears with the Install engine button.
  • “Missing key” banner — if you choose the LLM engine without a key, a banner suggests Enter key or Use Google/Bing.

Status bar

At the bottom it shows the translation status (in progress, cached, completed, error or cancelled) and the message from the engine in use.

Navigation

  • Buttons ◀ Prev / Next ▶ and the page number box.
  • Keyboard: ← → arrow keys and PageUp/PageDown.
  • Table of contents (TOC): click 📑 Contents and choose an entry to jump to the chapter.
  • Zoom: 🔍−/🔍+, Ctrl++ / Ctrl+−, Ctrl+0 to reset. The value 1.00× fits the page to the window; the label shows the current scale.
  • Resume: if enabled in Settings, the app reopens the document at the last page read.

Translation

Translation is page by page and starts only from the ▶ Translate button: browsing does not translate automatically.

  1. Open ⚙️ Settings → Language and choose the document language (source) and the target language.
  2. Choose the engine in the bar of the right panel.
  3. Press ▶ Translate (or Ctrl+E to export).

How it works

  • While the page is being produced, a “liquid” fill shows the estimated progress over the preview, with an Cancel button that stops the subprocess immediately.
  • A toast indicates the engine in use (⏳ Translating with engine…) and disappears when the result arrives.
  • The disk cache avoids re-translating the same page: it is indexed by document + engine + language pair.
  • If that page is already translated in the cache with an other engine and you change engine, the app asks for confirmation before deleting it to make room for the new translation.
  • Google's free chain can fall back to Microsoft and then LLM: a notice reports the fallback.
Warning Translation requires an Internet connection and sends the page text to an external service. Do not translate confidential documents unless you have the right to do so.

Translation engines

EngineDescriptionKey
Google Free chain gtranslate_cli.py: dict-chrome-ex → translate-pa → gtx, with fallback to Microsoft and then LLM. No
Bing Bing translator built into pdf2zh_next. No
LLM OpenAI-compatible path (--openai) pointed at OpenRouter. Yes

The engine can be changed on the fly from the bar or from ⚙️ Settings: the choice is saved. Google and Bing are free and require no registration; the OpenRouter key is needed only for the LLM engine and for the last fallback of the free chain.

OpenRouter key

The LLM engine requires an OPENROUTER_API_KEY. You can enter it from ⚙️ Settings → Cloning engine, where you will also find the Verify button.

Where it is stored and which one wins

  • The key is stored in a protected per-user file (keystore.py, permissions 0600) in the app's data folder — never in config.json, the logs or the command arguments.
  • The stored key takes precedence over the system variable OPENROUTER_API_KEY, which remains the fallback. Settings shows which key is active; if the variable is set but ignored, the app reports it.
  • If the variable was set after the app started (typical on Windows), the app warns that the variable was not inherited.

Verification and errors

Before translating with the LLM the key is verified without blocking the GUI. Errors are classified with a suggestion:

OutcomeMeaning
Invalid keyThe key is wrong or revoked.
Access deniedThe key does not have permissions for the model.
Credit exhaustedThe OpenRouter credit has run out.
Too many requestsRate limit: try again shortly.
Model unavailableThe model cannot be reached.
Network errorConnection missing or unstable.
If you run into problems you can always fall back to the Google or Bing engine, which do not require a key.

Export

With 💾 Export a 5-step guided procedure opens: File → Pages → Languages → Engine → Output.

  1. File — the starting document.
  2. Pages — current page or range, with large live previews of the first and last page of the selection. Each preview shows the physical number and the printed one (/PageLabels) when they differ.
  3. Languages — source and target language.
  4. Engine — the translation engine and the time estimate.
  5. Output — a single PDF, single pages in a ZIP or single pages in a folder, plus the destination folder and the name.

Choosing pages (current, range, list)

Destination and format

The Output step decides where and how to save.

  • Destination folder — choose it with Choose folder…; the app remembers it for later exports (by default it is the folder of the open PDF).
  • File name (or folder name in the third format) — editable; the automatic name includes selection, engine and language.
  • Format:
    • Single PDF — one file with the chosen pages.
    • Single pages in a ZIP — an archive with <name>_pNNNN.pdf.
    • Single pages in a folder — a dedicated subfolder in the chosen folder, with the same loose files.
Copy to Downloads When the export finishes, the ⬇ Copy to Downloads button copies the result to the system's Downloads folder; the original stays where you saved it.

Pre-translation and progress

Pages not yet in the cache can be translated before export, with immediate cancellation. The progress window shows the page currently being processed, advancing page by page; at the end of the process you will find the ⬇ Save to Downloads button.

Quick export

From the 💾 button menu you can export the current page only, without going through the wizard.

Settings

The ⚙️ Settings menu gathers language, engine and preferences; it is shown in the chosen interface language.

Language

  • Interface language — it/en/fr/de/es; changes the whole UI immediately.
  • Document language (source) — the language of the PDF; auto for automatic detection.
  • Translation language (target) — the language to translate into.

Translation

  • Translation engine — Google, Bing or LLM.

Cloning engine

  • Path to pdf2zh_next — empty for auto-detection; otherwise the path to the binary.
  • Install engine — installs the engine next to the executable (or in the data folder, if the former is not writable).
  • OpenRouter key — entry and Verify (see OpenRouter key).

Text

  • Font size — 10–16 pt.
  • Markdown rendering — on/off.
  • Save text edits — saves the edits made in the text windows per document.
  • 🗑️ Clear saved edits — deletes the saved edits of the current document (with confirmation).

Display and behaviour

  • Startup zoom — base render resolution (0.5×–4.0×).
  • Resume from last page — per document.
  • Remember last tab — of the right panel.

Everything is saved in config.json in the app's data folder (created on first launch with the OS language or Italian) and survives updates. See Uninstallation for the location per platform.

Installation

The packages are built with PyInstaller on native runners and published on the releases page. The binary includes the GUI and uv: the engine is installed next to the executable (see Cloning engine).

Windows (x64)

  1. Download NoesisPDFCloner-windows-x64-setup.exe (installer) or NoesisPDFCloner-windows-x64.exe (portable).
  2. Run the installer or execute the portable file.
  3. You may need to allow execution on first launch (SmartScreen).

Requirements: Windows 10/11 x64.

macOS (x64 / Apple Silicon)

  1. Download NoesisPDFCloner-macos-x64.dmg (Intel) or NoesisPDFCloner-macos-arm64.dmg (Apple Silicon).
  2. Open the .dmg and drag the app into Applications.
  3. On first launch, if the app is not signed: right-click → Open and confirm to get around Gatekeeper.

Requirements: macOS 11 or later.

Linux (x86_64)

  1. Download NoesisPDFCloner-x86_64.AppImage.
  2. Make it executable: 
    chmod +x NoesisPDFCloner-x86_64.AppImage
  3. Run it: 
    ./NoesisPDFCloner-x86_64.AppImage

Requirements: Linux x86_64 with FUSE and the Qt6 libraries. If FUSE is not available, use --appimage-extract-and-run.

From source (developers)

You need Python 3.12 and uv. The script creates the two venvs and opens the GUI:

./run.sh
./run.sh /percorso/file.pdf
Note Each update is applied by downloading the new package for the same platform. Preferences, cache and key stay in the app's data folder and are not touched.

Cloning engine

The engine is pdf2zh_next v2 (BabelDOC), installed in a dedicated environment .venv2 (Python 3.12) and invoked as a CLI subprocess. The GUI binary includes uv, so there is no need to install anything by hand.

Installing from the app

  • ⚙️ Settings → Cloning engine → Install engine.
  • Or from the Install engine button in the warning banner that appears in the right panel while the engine is missing.

Installation takes place next to the executable. If the app folder is not writable (e.g. C:\Program Files, or the AppImage running from a read-only mount), the engine is installed in the per-user data folder and the app detects it anyway.

Installing from the release scripts

./setup_engine.sh                                              # Linux / macOS
powershell -ExecutionPolicy Bypass -File .\setup_engine.ps1    # Windows

If uv is not present, the script downloads it itself.

Binary detection

The app looks for pdf2zh_next in this order:

  1. the path specified in ⚙️ Settings;
  2. the PDF2ZH_BIN environment variable;
  3. the .venv2 folder next to the app/repository.

Data and logs

  • Cache: in the app's data folder, subfolder clones/, keyed by document + engine + language pair.
  • Logs: <data folder>/logs/noesis-pdf-cloner.log.
  • Data folder location: Windows %APPDATA%\noesis-pdf-cloner\, macOS ~/Library/Application Support/noesis-pdf-cloner/, Linux ~/.local/share/noesis-pdf-cloner/.

Uninstallation

Uninstallation consists of removing the program and, if you wish, the user data folder (config, cache, key, logs).

Windows

  1. Uninstall from Control Panel, or delete the portable executable.
  2. To also remove the user data, delete %APPDATA%\noesis-pdf-cloner\.

macOS

  1. Drag the app to the Trash.
  2. To also remove the user data, delete ~/Library/Application Support/noesis-pdf-cloner/.

Linux

  1. Delete the file NoesisPDFCloner-x86_64.AppImage.
  2. To also remove the user data, delete ~/.local/share/noesis-pdf-cloner/.
Warning The data folder contains preferences, cache and key: deleting it is irreversible. If you intend to reinstall, you can keep it.

FAQ

The ▶ Translate button does nothing / says the engine is missing.

The cloning engine is not installed: use Install engine in the banner of the right panel or in ⚙️ Settings (see Cloning engine).

I chose the LLM engine but it asks for a key.

The LLM engine uses OpenRouter and requires OPENROUTER_API_KEY. Enter it in ⚙️ Settings and press Verify, or fall back to Google/Bing (see OpenRouter key).

Translation does not start or is slow.

Check the Internet connection and that the engine is selected. The free chain can fall back to Microsoft/LLM: look at the notice in the status bar. You can cancel with the Cancel button.

Why is a page already translated?

The cache is kept per document + engine + language pair. If you change engine on a page already in the cache with another engine, the app asks for confirmation before replacing it.

How do I change the interface language?

⚙️ Settings → Language → Interface language.

The app does not detect pdf2zh_next.

Specify the path to the binary in ⚙️ Settings, or set the PDF2ZH_BIN variable. The app also looks for .venv2 next to the executable (see Cloning engine).

Is a new version available?

Releases are published on the project's GitHub page: download the package for your platform. Preferences, cache and key stay intact.
