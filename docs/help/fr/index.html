Noesis PDF Cloner — Aide

Bienvenue dans l'aide complète. Noesis PDF Cloner ouvre un PDF et affiche à gauche la page originale et à droite la même page traduite avec la mise en page préservée. Vous y trouverez la description des fonctionnalités, l'utilisation des moteurs de traduction, la gestion de la clé OpenRouter, l'exportation, l'installation et l'usage licite du programme.

Aperçu

Le clone traduit est produit par pdf2zh_next v2 (typesetter BabelDOC) : le texte, les images, les colonnes, les tableaux et les formules restent à leur place, tandis que le texte est traduit dans la langue choisie. La traduction est à la demande, page par page, avec un cache sur disque séparé par moteur et par paire de langues.

📖 Vue côte à côte

Page originale à gauche, clone traduit à droite, avec zoom synchronisé.

🧩 Mise en page préservée

Le clone conserve la mise en page, les figures, les tableaux et les formules de la page.

🌐 Trois moteurs

Google (chaîne gratuite avec repli), Bing et LLM via OpenRouter.

▶ Traduction à la demande

La page ne démarre qu'avec le bouton ▶ Traduire : aucune traduction automatique pendant la navigation.

🗂️ Cache par moteur

Au second accès, la page est instantanée ; en changeant de moteur, l'application demande confirmation.

💾 Exportation guidée

Assistant en 5 étapes : un PDF unique ou des pages individuelles en ZIP.

🔑 Clé protégée

La clé OpenRouter est enregistrée dans un fichier par utilisateur (0600) avec vérification.

🌍 Interface multilingue

Italiano, English, Français, Deutsch, Español — modifiable à la volée.

En résumé

  • Côte à côte : original et clone toujours comparés.
  • Contrôle : la traduction ne démarre que lorsque vous le souhaitez.
  • Zéro clé pour commencer : Google et Bing sont gratuits.

Pour commencer

  1. Lancez l'application (voir Installation) et assurez-vous que le moteur de clonage est installé.
  2. Cliquez sur 📂 Ouvrir un PDF dans la barre d'outils et choisissez un fichier.
  3. Dans ⚙️ Paramètres, choisissez la langue du document (source, y compris auto) et la langue de la traduction (cible).
  4. Choisissez le moteur dans la barre du panneau de droite (Google, Bing ou LLM).
  5. Appuyez sur ▶ Traduire : le clone apparaît à droite avec la mise en page intacte.
  6. Avec 💾 Exporter, vous enregistrez la page ou une plage (voir Exportation).
Conseil À la première ouverture, l'application peut reprendre à la dernière page du document (si l'option est active) et utilise la langue d'interface choisie. La traduction ne démarre pas toute seule : le bouton ▶ Traduire est toujours nécessaire.

Panneau de gauche — original

Affiche la page du PDF telle quelle, avec le sommaire (TOC) optionnel. Le zoom est partagé avec le panneau de droite, de sorte que les deux côtés restent alignés.

Panneau de droite — clone traduit

En haut se trouve la barre des moteurs avec les boutons radio Google / Bing / LLM et le bouton ▶ Traduire. La barre est réductible (chevron en haut à droite) : une fois réduite, l'espace revient à la page, qui se réadapte, et l'état est mémorisé entre les sessions.

  • Bandeau « moteur manquant » — si le moteur n'est pas installé, un bandeau apparaît avec le bouton Installer le moteur.
  • Bandeau « clé manquante » — si vous choisissez le moteur LLM sans clé, un bandeau propose Saisir la clé ou Utiliser Google/Bing.

Barre d'état

En bas, elle affiche l'état de la traduction (en cours, en cache, terminée, erreur ou annulée) et le message du moteur utilisé.

Navigation

  • Boutons ◀ Préc. / Suiv. ▶ et champ du numéro de page.
  • Clavier : flèches ← → et Page suiv./Page préc.
  • Sommaire (TOC) : cliquez sur 📑 Sommaire et choisissez une entrée pour sauter au chapitre.
  • Zoom : 🔍−/🔍+, Ctrl++ / Ctrl+−, Ctrl+0 pour réinitialiser. La valeur 1.00× adapte la page à la fenêtre ; l'étiquette indique l'échelle en cours.
  • Reprise : si elle est active dans les Paramètres, l'application rouvre le document à la dernière page lue.

Traduction

La traduction se fait page par page et ne démarre qu'avec le bouton ▶ Traduire : naviguer ne traduit pas automatiquement.

  1. Ouvrez ⚙️ Paramètres → Langue et choisissez la langue du document (source) et la langue de destination.
  2. Choisissez le moteur dans la barre du panneau de droite.
  3. Appuyez sur ▶ Traduire (ou Ctrl+E pour exporter).

Comment ça marche

  • Pendant que la page est produite, un remplissage « liquide » affiche la progression estimée au-dessus de l'aperçu, avec un bouton Annuler qui interrompt immédiatement le subprocess.
  • Un toast indique le moteur utilisé (⏳ Traduction avec moteur…) et disparaît à l'arrivée du résultat.
  • Le cache sur disque évite de retraduire la même page : il est indexé par document + moteur + paire de langues.
  • Si cette page est déjà traduite en cache avec un autre moteur et que vous changez de moteur, l'application demande confirmation avant de l'éliminer pour laisser place à la nouvelle traduction.
  • La chaîne gratuite de Google peut se replier sur Microsoft puis sur LLM : un avertissement signale le repli.
Attention La traduction nécessite une connexion Internet et envoie le texte de la page à un service externe. Ne traduisez pas de documents confidentiels sans en avoir le droit.

Moteurs de traduction

MoteurDescriptionClé
Google Chaîne gratuite gtranslate_cli.py : dict-chrome-ex → translate-pa → gtx, avec repli sur Microsoft puis LLM. Non
Bing Traducteur Bing intégré à pdf2zh_next. Non
LLM Parcours compatible OpenAI (--openai) pointant vers OpenRouter. Oui

Le moteur se change à la volée depuis la barre ou depuis ⚙️ Paramètres : le choix est enregistré. Google et Bing sont gratuits et ne demandent pas d'inscription ; la clé OpenRouter ne sert qu'au moteur LLM et au dernier repli de la chaîne gratuite.

Clé OpenRouter

Le moteur LLM nécessite une clé OPENROUTER_API_KEY. Vous pouvez la saisir depuis ⚙️ Paramètres → Moteur de clonage, où vous trouverez aussi le bouton Vérifier.

Où elle est enregistrée et laquelle gagne

  • La clé est enregistrée dans un fichier par utilisateur protégé (keystore.py, permissions 0600) dans le dossier de données de l'application — jamais dans config.json, dans les logs ou dans les arguments des commandes.
  • La clé enregistrée est prioritaire sur la variable système OPENROUTER_API_KEY, qui reste le repli. Les Paramètres indiquent quelle clé est active ; si la variable est définie mais ignorée, l'application le signale.
  • Si la variable a été définie après le lancement de l'application (cas typique sous Windows), l'application avertit que la variable n'a pas été héritée.

Vérification et erreurs

Avant de traduire avec le LLM, la clé est vérifiée sans bloquer l'interface. Les erreurs sont classées avec un conseil :

RésultatSignification
Clé non valideLa clé est erronée ou révoquée.
Accès refuséLa clé n'a pas les permissions pour le modèle.
Crédit épuiséLe crédit OpenRouter est terminé.
Trop de requêtesLimite de débit : réessayez bientôt.
Modèle non disponibleLe modèle n'est pas joignable.
Erreur réseauConnexion absente ou instable.
En cas de problème, vous pouvez toujours vous replier sur le moteur Google ou Bing, qui ne demandent pas de clé.

Exportation

Avec 💾 Exporter, une procédure guidée en 5 étapes s'ouvre : Fichier → Pages → Langues → Moteur → Sortie.

  1. Fichier — le document de départ.
  2. Pages — page actuelle ou plage, avec aperçus grands et en direct de la première et de la dernière page de la sélection. Chaque aperçu affiche le numéro physique et celui imprimé (/PageLabels) lorsqu'ils diffèrent.
  3. Langues — langue source et langue de destination.
  4. Moteur — le moteur de traduction et l'estimation du temps.
  5. Sortie — un seul PDF, pages séparées en ZIP ou pages séparées dans un dossier, plus le dossier de destination et le nom.

Choisir les pages (courante, plage, liste)

À l'étape Pages de l'assistant, vous choisissez quoi exporter avec trois modes, tous dans le même écran que les aperçus : les commandes sont en haut, donc le champ libre ne réduit pas les miniatures.

  • Les aperçus montrent la première et la dernière page de la sélection, avec la ligne « N pages · étiquette ».
  • Le décompte en cache / à traduire et l'estimation ne tiennent compte que des pages choisies.
  • Le nom de fichier utilise la forme compacte : livre_pag1,3,7-9_google_it.pdf.
  • Si la liste n'est pas valide, le champ est signalé et Suivant reste bloqué jusqu'à correction.
Miniatures schématiques Les petites pages ci-dessus ne sont pas un aperçu réel : elles montrent seulement quelles pages la sélection inclut.

Destination et format

L'étape Sortie décide où et comment enregistrer.

  • Dossier de destination — choisissez-le avec Choisir un dossier… ; l'app le mémorise pour les exports suivants (par défaut, le dossier du PDF ouvert).
  • Nom du fichier (ou nom du dossier dans le troisième format) — modifiable ; le nom automatique inclut la sélection, le moteur et la langue.
  • Format :
    • Un seul PDF — un fichier avec les pages choisies.
    • Pages séparées en ZIP — une archive avec <nom>_pNNNN.pdf.
    • Pages séparées dans un dossier — un sous-dossier dédié dans le dossier choisi, avec les mêmes fichiers séparés.
Copier dans Téléchargements À la fin de l'export, le bouton ⬇ Copier dans Téléchargements copie le résultat dans le dossier Téléchargements ; l'original reste à l'endroit choisi.

Traduction préalable et progression

Les pages pas encore en cache peuvent être traduites avant l'export, avec annulation immédiate. La fenêtre de progression montre la page en cours de traitement, qui avance page par page ; en fin de processus, vous trouvez le bouton ⬇ Enregistrer dans Téléchargements.

Export rapide

Depuis le menu du bouton 💾, l'export de la seule page actuelle est disponible, sans passer par l'assistant.

Paramètres

Le menu ⚙️ Paramètres regroupe la langue, le moteur et les préférences ; il est affiché dans la langue d'interface choisie.

Langue

  • Langue de l'interface — it/en/fr/de/es ; change immédiatement toute l'interface.
  • Langue du document (source) — la langue du PDF ; auto pour la détection automatique.
  • Langue de traduction (cible) — la langue dans laquelle traduire.

Traduction

  • Moteur de traduction — Google, Bing ou LLM.

Moteur de clonage

  • Chemin de pdf2zh_next — vide pour la détection automatique ; sinon le chemin du binaire.
  • Installer le moteur — installe le moteur à côté de l'exécutable (ou dans le dossier de données, si le premier n'est pas accessible en écriture).
  • Clé OpenRouter — saisie et Vérifier (voir Clé OpenRouter).

Texte

  • Taille de police — 10–16 pt.
  • Rendu Markdown — on/off.
  • Enregistrer les modifications de texte — enregistre par document les modifications faites dans les fenêtres de texte.
  • 🗑️ Effacer les modifications enregistrées — supprime les modifications enregistrées du document actuel (avec confirmation).

Affichage et comportement

  • Zoom initial — résolution de base du rendu (0.5×–4.0×).
  • Reprendre à la dernière page — par document.
  • Mémoriser le dernier onglet — du panneau de droite.

Tout est enregistré dans config.json dans le dossier de données de l'application (créé au premier lancement avec la langue de l'OS ou l'italien) et survit aux mises à jour. Voir Désinstallation pour l'emplacement par plateforme.

Installation

Les paquets sont compilés avec PyInstaller sur des runners natifs et publiés sur la page des versions. Le binaire inclut l'interface et uv : le moteur s'installe à côté de l'exécutable (voir Moteur de clonage).

Windows (x64)

  1. Téléchargez NoesisPDFCloner-windows-x64-setup.exe (installateur) ou NoesisPDFCloner-windows-x64.exe (portable).
  2. Lancez l'installateur ou exécutez le fichier portable.
  3. Il peut être nécessaire d'autoriser l'exécution au premier lancement (SmartScreen).

Prérequis : Windows 10/11 x64.

macOS (x64 / Apple Silicon)

  1. Téléchargez NoesisPDFCloner-macos-x64.dmg (Intel) ou NoesisPDFCloner-macos-arm64.dmg (Apple Silicon).
  2. Ouvrez le .dmg et glissez l'application dans Applications.
  3. Au premier lancement, si l'application n'est pas signée : clic droit → Ouvrir et confirmez pour contourner Gatekeeper.

Prérequis : macOS 11 ou ultérieur.

Linux (x86_64)

  1. Téléchargez NoesisPDFCloner-x86_64.AppImage.
  2. Rendez-le exécutable : 
    chmod +x NoesisPDFCloner-x86_64.AppImage
  3. Lancez-le : 
    ./NoesisPDFCloner-x86_64.AppImage

Prérequis : Linux x86_64 avec FUSE et les bibliothèques Qt6. Si FUSE n'est pas disponible, utilisez --appimage-extract-and-run.

Depuis les sources (développeurs)

Il faut Python 3.12 et uv. Le script crée les deux venv et ouvre l'interface :

./run.sh
./run.sh /percorso/file.pdf
Remarque Chaque mise à jour s'applique en téléchargeant le nouveau paquet de la même plateforme. Les préférences, le cache et la clé restent dans le dossier de données de l'application et ne sont pas touchés.

Moteur de clonage

Le moteur est pdf2zh_next v2 (BabelDOC), installé dans un environnement dédié .venv2 (Python 3.12) et invoqué comme subprocess CLI. Le binaire de l'interface inclut uv, il n'est donc pas nécessaire d'installer quoi que ce soit à la main.

Installation depuis l'application

  • ⚙️ Paramètres → Moteur de clonage → Installer le moteur.
  • Ou depuis le bouton Installer le moteur dans le bandeau d'avertissement qui apparaît dans le panneau de droite tant que le moteur manque.

L'installation se fait à côté de l'exécutable. Si le dossier de l'application n'est pas accessible en écriture (par ex. C:\Program Files, ou l'AppImage exécutée depuis un montage en lecture seule), le moteur est installé dans le dossier de données par utilisateur et l'application le détecte quand même.

Installation depuis les scripts de la version

./setup_engine.sh                                              # Linux / macOS
powershell -ExecutionPolicy Bypass -File .\setup_engine.ps1    # Windows

Si uv n'est pas présent, le script le télécharge tout seul.

Détection du binaire

L'application cherche pdf2zh_next dans cet ordre :

  1. le chemin indiqué dans ⚙️ Paramètres ;
  2. la variable d'environnement PDF2ZH_BIN ;
  3. le dossier .venv2 à côté de l'application/du dépôt.

Données et logs

  • Cache : dans le dossier de données de l'application, sous-dossier clones/, avec une clé par document + moteur + paire de langues.
  • Logs : <cartella dati>/logs/noesis-pdf-cloner.log.
  • Emplacement du dossier de données : Windows %APPDATA%\noesis-pdf-cloner\, macOS ~/Library/Application Support/noesis-pdf-cloner/, Linux ~/.local/share/noesis-pdf-cloner/.

Désinstallation

La désinstallation consiste à supprimer le programme et, si vous le souhaitez, le dossier de données utilisateur (config, cache, clé, logs).

Windows

  1. Désinstallez depuis le Panneau de configuration, ou supprimez l'exécutable portable.
  2. Pour supprimer aussi les données utilisateur, effacez %APPDATA%\noesis-pdf-cloner\.

macOS

  1. Glissez l'application dans la Corbeille.
  2. Pour supprimer aussi les données utilisateur, effacez ~/Library/Application Support/noesis-pdf-cloner/.

Linux

  1. Supprimez le fichier NoesisPDFCloner-x86_64.AppImage.
  2. Pour supprimer aussi les données utilisateur, effacez ~/.local/share/noesis-pdf-cloner/.
Attention Le dossier de données contient les préférences, le cache et la clé : le supprimer est irréversible. Si vous comptez réinstaller, vous pouvez le conserver.

FAQ

Le bouton ▶ Traduire ne fait rien / dit que le moteur manque.

Le moteur de clonage n'est pas installé : utilisez Installer le moteur dans le bandeau du panneau de droite ou dans ⚙️ Paramètres (voir Moteur de clonage).

J'ai choisi le moteur LLM mais il demande une clé.

Le moteur LLM utilise OpenRouter et nécessite OPENROUTER_API_KEY. Saisissez-la dans ⚙️ Paramètres et appuyez sur Vérifier, ou repliez-vous sur Google/Bing (voir Clé OpenRouter).

La traduction ne démarre pas ou est lente.

Vérifiez la connexion Internet et que le moteur est sélectionné. La chaîne gratuite peut se replier sur Microsoft/LLM : regardez l'avertissement dans la barre d'état. Vous pouvez annuler avec le bouton Annuler.

Pourquoi une page est-elle déjà traduite ?

Le cache conserve par document + moteur + paire de langues. Si vous changez de moteur sur une page déjà en cache avec un autre moteur, l'application demande confirmation avant de la remplacer.

Comment changer la langue de l'interface ?

⚙️ Paramètres → Langue → Langue de l'interface.

L'application ne détecte pas pdf2zh_next.

Indiquez le chemin du binaire dans ⚙️ Paramètres, ou définissez la variable PDF2ZH_BIN. L'application cherche aussi .venv2 à côté de l'exécutable (voir Moteur de clonage).

Une nouvelle version est-elle disponible ?

Les versions sont publiées sur la page GitHub du projet : téléchargez le paquet de votre plateforme. Les préférences, le cache et la clé restent intacts.
