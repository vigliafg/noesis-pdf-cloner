Noesis PDF Cloner — Ayuda

Bienvenido a la ayuda completa. Aquí encontrarás la descripción de todas las funciones, las instrucciones de instalación y desinstalación para cada plataforma y la información sobre el uso lícito del programa.

Funciones

Noesis PDF Cloner es un lector de PDF con un motor de extracción de texto adaptativo que reconstruye automáticamente el orden de lectura de la página. En comparación con el proyecto padre, esta versión usa un solo motor de renderizado (PyMuPDF) y un solo motor de extracción (PyMuPDF4LLM), sin selector en tiempo de ejecución: todo es automático, con la posibilidad de intervenir manualmente cuando sea necesario.

📄 Extracción inteligente

El texto de la página se extrae en Markdown con el orden de lectura correcto: columnas, tablas, títulos, leyendas.

🔍 Vista lado a lado

Página renderizada a la izquierda, texto extraído a la derecha, con navegación, índice (TOC) y zoom.

🚫 Zonas de exclusión

Arrastra un recuadro rojo sobre el ruido (encabezados, pies, imágenes, leyendas) para eliminarlo del texto.

🟩 Zonas de inclusión

Los recuadros verdes numerados definen el orden de lectura manual para páginas complejas.

🖼️ Extracción de imágenes

Selecciona una zona de la página y guarda la figura recortada en la galería.

🌐 Traducción

Traduce la página al idioma de destino elegido, con caché en disco.

⚙️ Configuración

Idioma de la interfaz, idiomas de traducción, zoom, fuente, cabecera y comportamiento de lectura.

🌍 Interfaz multilingüe

Italiano, English, Français, Deutsch, Español — cambiable al instante.

En resumen

  • Automático por defecto: el motor adaptativo decide el plan de lectura de cada página.
  • Manual cuando haga falta: las zonas rojas y verdes intervienen solo si las dibujas tú.
  • Cero configuración para empezar: abre un PDF y lee.

Primeros pasos

  1. Inicia la aplicación (consulta Instalación para tu plataforma).
  2. Haz clic en 📂 Abrir PDF en la barra de herramientas y elige un archivo PDF.
  3. La página aparece a la izquierda, el texto extraído a la derecha.
  4. Usa ◀ Ant. / Sig. ▶, las flechas o el 📑 Índice para desplazarte por el documento.
  5. Si el texto contiene ruido, prueba las zonas de exclusión.
Consejo En el primer inicio la app abre en la última página del documento (si la opción «Reanudar en la última página» está activa) y en el idioma detectado del sistema operativo.

Panel derecho (texto)

Tres pestañas arriba a la derecha:

  • 📄 Original — el texto extraído (auto o manual).
  • 🇫🇷 … (bandera + idioma) — la traducción de la página al idioma de destino elegido en Configuración.
  • 🖼️ Imágenes — la galería de las figuras extraídas.

Las dos pestañas de texto (📄 Original y la traducción) son ventanas editables: puedes escribir, seleccionar, copiar y pegar libremente (Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+Z). Cada ventana tiene su mini barra de herramientas con A−, el tamaño actual y A+ para reducir o aumentar el texto en vivo, además de ↺ para restaurar el tamaño de Configuración y 💾 para exportar el texto de la ventana como .md o .txt (con tus cambios, sin la cabecera). Con el guardado activo, un punto naranja ● junto a los botones avisa de cambios aún no escritos en el disco. Las dos ventanas hacen zoom de forma independiente. Tras una modificación, el texto se muestra como texto sin formato. Los cambios se guardan por página (carpeta de datos de la aplicación) y vuelven al reabrir el documento.

Barra de estado

Abajo muestra la página actual, el documento y el tiempo de extracción, además de los mensajes relativos a las zonas.

Navegación

  • Botones: ◀ Ant. / Sig. ▶ y la casilla del número de página.
  • Teclado: flechas ← → y RePág/AvPág.
  • Índice (TOC): haz clic en 📑 Índice y elige una entrada para saltar al capítulo.
  • Zoom: botones 🔍−/🔍+, Ctrl++ / Ctrl+−, Ctrl+0 para restablecer. 1,00× ajusta la página a la ventana; la etiqueta muestra la escala actual (0,25×–8,00×).
  • Reanudar: si está activado en Configuración, la app reabre el documento en la última página leída.

Extracción de texto

El texto se extrae con PyMuPDF4LLM y luego lo reordena el motor adaptativo, que elige automáticamente el plan de lectura (perfil → plan → pipeline): reordenación de columnas, reconocimiento de tablas, gestión de recuadros, leyendas y epígrafes, deduplicación de títulos y espaciados.

PDF escaneados Las páginas sin capa de texto se reconocen mediante el OCR Tesseract incluido en la app (paquetes Windows/macOS/Linux); el idioma del OCR sigue el ajuste del idioma del documento (detección automática por defecto). La extracción se ejecuta en segundo plano, así que la interfaz sigue respondiendo, y los resultados se guardan en caché por página.

Cabecera de extracción

Si está activada (Configuración → «Mostrar la cabecera de extracción»), aparece una línea informativa encima del texto:

── Backend: PyMuPDF4LLM ⚡ │ 210 ms │ 12 345 caracteres │ Fix: Motor adaptativo │ OCR: 🌐 Auto │ Trad.: Google Translate ──

El nombre del motor en la cabecera refleja siempre el motor activo: cambiarlo en vivo actualiza la línea sobre el texto original y el traducido.

Renderizado Markdown

El texto se muestra como Markdown renderizado (incluidas tablas y formato). Con 📝 MD ✓ puedes pasar a texto plano. Atajo: Ctrl+M.

Nota La extracción trabaja sobre el texto de la página. Las imágenes que contienen texto pueden generar ruido: usa las zonas de exclusión para eliminarlo.

Zonas de exclusión (rojas)

Cuando una página contiene elementos que no forman parte de la lectura (encabezados, pies, números de página, imágenes con texto, leyendas, publicidad), puedes excluirlos manualmente:

  1. Haz clic en 🚫 Excluir zona.
  2. Arrastra con el ratón un recuadro rojo sobre el contenido que quieras eliminar.
  3. El texto se recalcula inmediatamente sin ese contenido.
  4. Pulsa el botón de nuevo para terminar.

Excluir + extraer en un solo gesto

Si la zona roja contiene una imagen incrustada, toda la zona seleccionada se captura automáticamente en la pestaña 🖼️ Imágenes (las figuras compuestas — varias imágenes, imagen + leyenda — se conservan completas, no solo un fragmento; el foco permanece en la ventana de texto Original). La barra de estado confirma la operación.

Atención La exclusión es por página y vive solo en memoria: al cerrar la app las zonas se pierden.

Zonas de inclusión (verdes)

Para las páginas con un diseño complejo (p. ej. varias columnas o recuadros dispersos) puedes definir tú mismo el orden de lectura con los recuadros verdes numerados:

  1. Haz clic en 🟩 Incluir zona.
  2. Arrastra un recuadro verde sobre la primera columna/región de lectura (aparece el número 1).
  3. Dibuja el siguiente recuadro en orden de lectura (2, 3, …).
  4. El texto se reconstruye siguiendo la numeración.

Reglas

  • Un recuadro verde = una columna/región. No uses un solo recuadro para abarcar dos columnas.
  • Lista blanca: con al menos un recuadro verde, todo lo que queda fuera de los recuadros se descarta.
  • Dentro de un recuadro: orden de arriba a abajo y luego de izquierda a derecha.
  • Composición: las rojas eliminan primero el ruido, las verdes ordenan lo que queda; donde se solapan, gana el rojo.

Extracción de imágenes

Puedes recortar una figura directamente de la página:

  1. Haz clic en 🖱️ Seleccionar zona.
  2. Arrastra un rectángulo sobre la figura.
  3. La imagen se guarda en la pestaña 🖼️ Imágenes.

En la galería cada imagen tiene los botones:

  • 💾 Guardar — guarda en un archivo (PNG/JPEG).
  • 📋 Copiar — copia al portapapeles.
  • 🗑️ Eliminar — borra de la galería.
  • Clic en la vista previa para ampliar.

Las imágenes extraídas se guardan en la carpeta de datos de la app y se conservan entre un inicio y otro.

Traducción

El panel derecho puede mostrar la página traducida al idioma de destino elegido (por defecto: italiano).

  1. Abre ⚙️ Configuración → sección Idioma.
  2. Elige el idioma del documento (origen; «auto» para la detección automática) y el idioma de la traducción (destino).
  3. Haz clic en la pestaña con bandera + nombre del idioma de destino en el panel derecho.

Cómo funciona

  • La traducción se ejecuta en segundo plano con el motor elegido en ⚙️ Configuración — Google Translate (por defecto) o Microsoft Edge, ambos gratuitos y sin clave API. También puedes cambiar de motor en vivo con los botones de radio Google / Microsoft a la izquierda de la barra de pestañas de traducción: la elección se guarda, la página actual se vuelve a traducir y un aviso confirma el cambio durante 2 segundos.
  • Mientras se produce la traducción, aparece un aviso (⏳ Traduciendo con motor…) sobre el texto traducido; desaparece cuando aparece el resultado.
  • La caché en disco evita volver a traducir la misma página: está indexada por página e idioma de destino.
  • Mientras dibujas zonas, la traducción se difiere con una pausa de 600 ms (sin ráfagas de peticiones).
  • Si cambias el idioma de destino, la pestaña se actualiza y la página se vuelve a traducir.
Atención La traducción requiere conexión a Internet y envía el texto de la página a un servicio externo. No traduzcas documentos confidenciales sin tener derecho a hacerlo.

Configuración

El menú ⚙️ Configuración (arriba a la derecha) reúne todo lo relacionado con el idioma y las preferencias. Se muestra en el idioma de la interfaz elegido y la vista previa del idioma es en directo.

Idioma

  • Idioma de la interfaz — it/en/fr/de/es; cambia al instante toda la interfaz (el texto del PDF se mantiene en el idioma original).
  • Idioma del documento (origen) — el idioma del PDF; «auto» para la detección automática.
  • Idioma de la traducción (destino) — el idioma al que traducir el texto.

Traducción

  • Motor de traducción — Google Translate (por defecto) o Microsoft Edge (gratis), sin clave API. Cambiarlo vuelve a traducir la página actual. Google Translate cambia automáticamente entre tres endpoints gratuitos (dict-chrome-ex → translate-pa → gtx): si el servicio está bloqueado en tu red, aparece un aviso en lugar de mostrar silenciosamente el texto sin traducir.

Texto

  • Tamaño de fuente — 10–16 pt.
  • Renderizado Markdown — activado/desactivado.
  • Mostrar la cabecera de extracción — activado/desactivado.
  • Guardar cambios de texto — guarda los cambios hechos en las ventanas Original/Traducción por documento (activo por defecto).
  • 🗑️ Borrar cambios guardados — elimina los cambios guardados del documento actual (con confirmación).

Visualización

  • Zoom inicial — resolución base del renderizado, 0,5×–4,0× (afecta a la nitidez; la escala visible empieza en 1,00× = ajustar).

Comportamiento

  • Reanudar en la última página — por documento.
  • Recordar la última pestaña — del panel derecho.

Todo se guarda en el archivo config.json de la carpeta de datos de la app (creado en el primer inicio con el idioma del SO o italiano) y sobrevive a las actualizaciones. Consulta Desinstalación para la ubicación exacta por plataforma.

Instalación

El programa es portátil: no existe un instalador real. Descargas el paquete de tu plataforma desde la página de versiones del proyecto en GitHub y lo ejecutas.

Windows (x64)

  1. Descarga NoesisPDFReaderLite-windows-x64.exe.
  2. Doble clic en el archivo para iniciar la app (puede quedarse en la carpeta Descargas).
  3. Sin instalación, sin servicio, sin entrada de registro obligatoria.

Requisitos: Windows 10/11 x64. SmartScreen puede pedir confirmación en el primer inicio.

macOS (x64 / Apple Silicon)

  1. Descarga NoesisPDFReaderLite-macos-x64.dmg (Mac Intel) o NoesisPDFReaderLite-macos-arm64.dmg (Apple Silicon).
  2. Abre el .dmg y arrastra la app a la carpeta Aplicaciones.
  3. En el primer inicio la app no está firmada: clic derecho sobre la app → Abrir y confirma para saltarte Gatekeeper.

Requisitos: macOS 11 o posterior.

Linux (x86_64)

  1. Descarga NoesisPDFReaderLite-x86_64.AppImage.
  2. Hazlo ejecutable: 
    chmod +x NoesisPDFReaderLite-x86_64.AppImage
  3. Ejecútalo con doble clic o desde la terminal: 
    ./NoesisPDFReaderLite-x86_64.AppImage

Requisitos: Linux x86_64 con FUSE (para el AppImage) y las bibliotecas Qt6. Si FUSE no está disponible, extrae el AppImage con --appimage-extract-and-run.

Desde el código fuente (desarrolladores)

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
Nota Cada actualización se aplica descargando y ejecutando el nuevo paquete de la misma plataforma. Las preferencias (config.json, caché, imágenes) permanecen en la carpeta de datos de la app y no se tocan.

Desinstalación

Al ser portátil, desinstalar consiste en eliminar los archivos del programa y, si lo deseas, la carpeta de datos de usuario.

Windows

  1. Elimina NoesisPDFReaderLite-windows-x64.exe.
  2. Para eliminar también los datos de usuario, borra la carpeta %APPDATA%\noesis-pdf-cloner\ (config, caché de traducción, imágenes).

macOS

  1. Arrastra la app de la carpeta Aplicaciones a la Papelera.
  2. Para eliminar también los datos de usuario, borra la carpeta ~/Library/Application Support/noesis-pdf-cloner/.

Linux

  1. Elimina el archivo NoesisPDFReaderLite-x86_64.AppImage.
  2. Para eliminar también los datos de usuario, borra la carpeta ~/.local/share/noesis-pdf-cloner/.
Atención La carpeta de datos contiene tus preferencias e imágenes extraídas: borrarla es irreversible. Si piensas reinstalar, puedes conservarla.

Preguntas frecuentes

¿Por qué el texto extraído contiene palabras que no veo en la página?

Probablemente son textos dentro de imágenes (figuras, diagramas) que pasan por el OCR. Usa una zona de exclusión sobre el recuadro de la imagen para eliminarlos.

El orden de lectura no es correcto en una página compleja.

Usa las zonas de inclusión verdes para definir manualmente el orden de las columnas.

Mis zonas desaparecen al cerrar la app.

Sí: las zonas (rojas y verdes) viven en memoria y son por página. Las preferencias, en cambio, se guardan en el config.

¿Cómo cambio el idioma de la interfaz?

⚙️ Configuración → Idioma → Idioma de la interfaz.

La traducción no arranca.

Comprueba la conexión a Internet y que la pestaña del idioma de destino esté activa. La traducción se difiere mientras dibujas zonas.

¿Hay una versión nueva disponible?

Las versiones se publican en la página de GitHub del proyecto: descarga el paquete de tu plataforma y ejecútalo. Las preferencias se mantienen intactas.
