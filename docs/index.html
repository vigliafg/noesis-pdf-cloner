PDF tradotti con il layout intatto

Apri un PDF e vedi a sinistra la pagina originale e a destra la stessa pagina tradotta: testo, immagini, colonne, tabelle e formule restano al loro posto. La traduzione è on-demand, pagina per pagina, con cache su disco.

⬇ Scarica l'ultima release 📖 Leggi la guida 🐙 GitHub

Panoramica

Un lettore PDF affiancato a un motore di clonazione che ricostruisce la pagina tradotta senza perdere l'impaginazione.

📖 Vista affiancata

Pagina originale a sinistra, clone tradotto a destra, con zoom sincronizzato sui due pannelli.

🧩 Layout preservato

Il clone è prodotto da pdf2zh_next v2 (typesetter BabelDOC): colonne, tabelle, figure e formule restano dove sono.

🌐 Tre motori

Google (catena gratuita con fallback), Bing e LLM via OpenRouter. Si cambiano al volo.

▶ Traduzione on-demand

Niente traduzione automatica cambiando pagina: la pagina parte solo quando premi ▶ Traduci. Al secondo accesso è istantanea, dalla cache.

🗂️ Cache intelligente

Una cache per documento + motore + coppia linguistica. Cambiando motore su una pagina già tradotta, l'app chiede conferma prima di sostituirla.

💾 Esportazione guidata

Un wizard a 5 passi per esportare la pagina corrente o un intervallo: un PDF unito o pagine singole in ZIP.

🔑 Chiave OpenRouter

Salvata in un file per-utente protetto (0600), con verifica e messaggi d'errore chiari. Vince sulla variabile di sistema.

🌍 Interfaccia multilingue

Italiano, English, Français, Deutsch, Español — cambiabile al volo senza riavviare.

Motori di traduzione

Si scelgono dalla fascia nel pannello destro o da ⚙️ Impostazioni.

MotoreCome funzionaChiave API
Google Catena gratuita gtranslate_cli.py: dict-chrome-ex → translate-pa → gtx, con fallback automatico su Microsoft e poi LLM. Un avviso segnala i fallback. No
Bing Traduttore Bing integrato in pdf2zh_next. No
LLM Percorso OpenAI-compatibile di pdf2zh_next (--openai) puntato a OpenRouter. Sì (OPENROUTER_API_KEY)
Nessuna chiave per iniziare Google e Bing sono gratuiti e non richiedono registrazione. La chiave OpenRouter serve solo per il motore LLM e per l'ultimo fallback della catena gratuita.

Come funziona

Quattro passi, dal PDF all'export.

Apri il PDF

La pagina originale compare a sinistra, con indice, navigazione e zoom.

Scegli lingua e motore

Lingua del documento (anche auto) e lingua di destinazione, più il motore di traduzione.

Premi ▶ Traduci

Il clone arriva nel pannello destro con il layout intatto; un riempimento “liquido” mostra il progresso e puoi annullare in ogni momento.

Esporta

Salva la pagina o un intervallo come PDF unico o come pagine singole in uno ZIP, direttamente in Download.

Esportazione

Procedura guidata in 5 passi: File → Pagine → Lingue → Motore → Output.

📄 Pagine

Pagina corrente o intervallo, con anteprime grandi e live della prima e dell'ultima pagina.

🔢 Doppia numerazione

Il numero fisico e quello stampato (/PageLabels) quando differiscono.

📦 Formato

Un unico PDF oppure pagine singole in un archivio ZIP.

⬇ Salva in Download

A fine processo un pulsante copia il risultato nella cartella Download.

Dal menu del pulsante 💾 è disponibile anche l'export rapido della sola pagina corrente, senza wizard.

Motore di clonazione

Il binario include la GUI e uv; il motore pdf2zh_next si installa accanto all'eseguibile. Puoi farlo dall'app (⚙️ Impostazioni → Installa motore), oppure con lo script incluso nella release:

./setup_engine.sh                                              # Linux / macOS
powershell -ExecutionPolicy Bypass -File .\setup_engine.ps1    # Windows

L'app rileva automaticamente la cartella .venv2 accanto all'eseguibile; in alternativa puoi indicare il percorso del binario in ⚙️ Impostazioni.

Da sorgente

Serve Python 3.12 e uv: lo script run.sh crea i due ambienti virtuali e apre la GUI.

git clone https://github.com/vigliafg/noesis-pdf-cloner.git
cd noesis-pdf-cloner
./run.sh
Due venv separati .venv ospita l'app (PyQt6 + PyMuPDF), .venv2 il motore pdf2zh_next (Python 3.12): non convivono, e il motore viene invocato come subprocess CLI.
